Nokia 3310 SMS Emulator to aplikacja internetowa, która odtwarza retro doświadczenie korzystania z kultowego telefonu komórkowego.

Projekt łączy:
  Frontend (React / TypeScript): Odwzorowuje interfejs LCD Nokii, mechanizm wpisywania tekstów za pomocą klawiatury multi-tap (T9) oraz ekrany menu, skrzynki odbiorczej i pisania wiadomości.
  
  Backend (Spring Boot / H2): Udostępnia REST API do obsługi komunikacji oraz dba o trwały zapis wiadomości w plikowej bazie danych.
